Эта папка НЕ обязательна к ручному заполнению — теперь приложение само
скачивает сюда sing-box.exe и wintun.dll при первом подключении на Windows
(см. lib/services/singbox_runtime_windows.dart, методы _downloadSingBox() /
_downloadWintun()). Клиенту твоего приложения ничего скачивать вручную не
нужно — при первом нажатии "Подключить" на Windows приложение само:

  1) спросит у GitHub API последний релиз sing-box (SagerNet/sing-box) и
     скачает windows-amd64.zip;
  2) скачает wintun.dll с официального wintun.net;
  3) распакует оба архива штатным Windows PowerShell (Expand-Archive —
     ничего дополнительно ставить не нужно);
  4) положит sing-box.exe и wintun.dll сюда, в эту же папку.

Так будет происходить один раз — при следующих подключениях файлы уже на
месте и повторно не скачиваются.

ЕСТЬ ДВА СПОСОБА РАБОТЫ — выбери, что удобнее:
------------------------------------------------------------------------

СПОСОБ A (по умолчанию, ничего делать не надо):
  Ничего в эту папку заранее класть не нужно. Единственное требование —
  на компьютере клиента при ПЕРВОМ подключении должен быть обычный
  интернет (не через VPN) — иначе скачивать не с чего. Дальше всё само.

СПОСОБ B (если хочешь, чтобы приложение работало даже без интернета при
первом запуске, или не доверяешь автозагрузке на машине клиента):
  Один раз вручную положи сюда:
    - sing-box.exe (windows-amd64) — https://github.com/SagerNet/sing-box/releases
    - wintun.dll (64-bit)          — https://www.wintun.net/
  и закоммить их в репозиторий. Тогда windows/CMakeLists.txt зашьёт их
  в каждую сборку — авто-скачивание в коде просто не сработает, потому что
  файлы уже будут на месте (проверка "если файла нет — скачать").

Оба способа совместимы одновременно и не конфликтуют.
